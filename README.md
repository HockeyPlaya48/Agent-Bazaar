# Agent Bazaar
Marketplace for AI Agent Skills & Capabilities | x402 Micropayments

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

## Structure

- `frontend/` — Next.js 14 app (TypeScript, Tailwind CSS)
- `backend/` — API server (coming soon)

## Install as an Agent Skill

Add Agent Bazaar to any AI agent with a single command:

```bash
npx skills add HockeyPlaya48/Agent-Bazaar@agent-bazaar
```

Works with Claude Code, Cursor, Copilot, Cline, and 40+ other agents. Compatible with [lobster.cash](https://lobster.cash) for wallet operations.

## Getting Started

### Frontend

```bash
cd frontend
npm install
npm run dev
```
