## Repository Description

**Short Description (for GitHub):**
```
TypeScript SDK for the x402 payment protocol. Enable any API to accept micropayments from AI agents via HTTP 402 Payment Required responses.
```

**Long Description:**
```
The x402 SDK provides a simple, standardized way to implement micropayments for API endpoints using the x402 protocol. Perfect for AI agent marketplaces, developer tools, and any API that wants to charge per-call rather than subscription-based pricing.

Features:
• Express.js middleware for providers (1-line paywall setup)  
• Client SDK for agents (automatic payment discovery & processing)
• Registry integration with Agent Bazaar
• TypeScript support with full type definitions
• Production-ready with comprehensive error handling
```
